# Transforming Wireframes into Static Web Pages

## Internship Task

This project is a beginner-level implementation of a wireframe concept
using HTML and CSS.

The main purpose of this project is to understand how a webpage design
can be converted into actual HTML and CSS code.

---

## Objective

The objective of this task is to create a static webpage from a
wireframe and make the webpage responsive on different screen sizes.

I focused on creating a simple and understandable webpage rather than
using complicated frameworks or libraries.

---

# CSS Techniques Used

## Flexbox

Flexbox was used for simple horizontal and vertical layouts.

For example, the header uses Flexbox to place the logo and navigation
on opposite sides.

---

## CSS Grid

CSS Grid was used for layouts containing multiple cards.

For example:

```css
.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}
```

---

## Media Queries

Media queries were used to make the webpage responsive.

For example:

```css
@media (max-width: 600px) {
    .cards {
        grid-template-columns: 1fr;
    }
}
```

This changes the three-column card layout into a single-column layout
on smaller screens.

---

# Responsive Design

The webpage was designed to work on:

* Desktop
* Laptop
* Tablet
* Mobile phone

On smaller screens:

* Navigation becomes easier to fit
* Hero content becomes one column
* Cards become one column
* About section becomes one column
* Process items become one column
* CTA content becomes vertical
* Footer content becomes vertical

# Challenges Faced

## Challenge 1: Creating the layout

As a beginner, understanding how different webpage sections should be
positioned was one of the first challenges.

### Solution

I divided the webpage into smaller sections and used CSS Grid and
Flexbox where necessary.

---

## Challenge 2: Responsive design

The desktop layout did not automatically look good on mobile devices.

### Solution

I used CSS media queries to change the layout when the screen width
became smaller.

---

## Challenge 3: Maintaining spacing

Different sections required different spacing to make the page readable.

### Solution

I used padding, margin and gap properties to create consistent
spacing between elements.
